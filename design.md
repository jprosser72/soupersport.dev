SouperSport Website — Visual Design Intent
Purpose
This document describes the visual design intent of the SouperSport project website (soupersport.dev).
It exists to make explicit the reasoning behind layout, color, typography, and decorative choices, so that future changes can be evaluated against intent, not personal preference or transient trends.
This document is normative for the website.
It is not a style guide for the SouperSport language itself.

Scope
This document governs:

Color palette choices
Typography characteristics
Layout and spacing principles
Decorative elements (e.g., dividers)
Light mode, dark mode, and print behavior

It does not cover:

Language semantics
Specification content
Documentation structure
Branding for third‑party or derivative uses


Relationship to the Canonical Project
This website is an entry point and overview.
The canonical source of truth for SouperSport — including specifications, releases, and semantic definitions — is the GitHub repository:

https://github.com/SouperSport/soupersport

Visual design decisions here are intended to support that repository, not compete with it.

Design Principles
The site’s visual design follows a small set of explicit principles, chosen to align with SouperSport’s broader philosophy.
1. Explicit over Implicit
Visual elements should communicate their role clearly.

Headings look like headings.
Links look like links.
Decorative elements do not masquerade as content.

Nothing relies on subtle or hidden cues to convey meaning.

2. Restraint over Ornamentation
The site intentionally avoids:

decorative backgrounds
animations
gradients used as primary structure
attention‑seeking UI elements

Decoration is allowed only when it:

reinforces identity, and
does not interfere with reading or comprehension.


3. Identity Anchored to the Logo
All color choices are derived directly from the SouperSport logo.
The logo is treated as the single source of truth for visual identity:

Deep brown tones anchor primary text and structure.
Warm sunset oranges are used sparingly as accents.
White is used as negative space to preserve clarity.

No additional colors are introduced unless they can be justified against the logo palette.

4. Typography as Tone, Not Branding
The website does not attempt to reproduce the logo’s typeface.
Instead, typography is tuned to echo the character of the wordmark:

Slightly heavier weights for confidence and stability
Mild negative letter‑spacing for solidity
Neutral system fonts for longevity and clarity

Readability takes precedence over stylistic novelty.

5. Minimalism with Rhythm
Spacing is deliberate and consistent.
Vertical rhythm is used to:

separate conceptual sections,
guide reading flow,
prevent visual fatigue.

Whitespace is treated as a structural element, not “empty space.”

Decorative Elements
Sunset Divider Motif
A single decorative element is used between major sections: the sunset divider.

It is horizontal, thin, and rounded.
It uses a subtle orange‑to‑amber gradient derived from the logo.
Its shape and coloration are intended to echo the arc of the logo’s sunset, not reproduce it literally.

The divider is decorative only:

it conveys no semantic information,
it must never be required for understanding content.


Light and Dark Modes
Light Mode (Default)
Light mode is the primary presentation.

White background prioritizes legibility and print‑friendliness.
Dark brown text reflects the logo without using pure black.
Orange accents are restrained and contextual.

Dark Mode (System‑Preferred)
A dark mode is provided via the user’s system or browser preference.
Dark mode design goals:

Avoid pure black; use deep, warm brown instead.
Preserve the warmth of the logo palette.
Maintain contrast without glare.
Ensure the white logo remains legible and dominant.

Dark mode is an alternative presentation, not the canonical one.

Print Behavior
When printed:

Decorative elements (including the sunset divider) are removed.
Text renders as black on white.
Links are underlined for clarity.

This ensures printed material prioritizes content over presentation.

Non‑Goals
The website explicitly does not aim to:

showcase UI innovation
function as an interactive application
mirror marketing sites or product landing pages
serve as a complete documentation portal

Its role is to orient, contextualize, and point to the canonical project.

Change Policy
Visual changes should be evaluated against this document.
Questions to ask before making changes:

Does this increase clarity?
Does this reinforce or dilute identity?
Does this introduce ambiguity or visual noise?
Is this change still correct five years from now?

If the answer is unclear, restraint is preferred.

Closing Statement
The SouperSport website is designed to be quietly confident.
Its visual language favors:

clarity over cleverness,
intent over fashion,
stability over expressiveness.

The site should feel correct first, and distinctive second.
